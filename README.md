Invoice Extraction System

An AI-powered Invoice Extraction system that automates the process of extracting structured information from invoices.
The application allows users to upload invoice files, preview extracted data, and store validated results in a database.

Features:
--AI-based text extraction using Gemini
--Preview extracted invoice fields before saving
--Structured storage of invoice data in PostgreSQL
--RESTful backend APIs using FastAPI
--Modern frontend built with React (Vite)

Tech Stack:
Frontend
--React
--Vite

Backend
--FastAPI
--Python
--Gemini (LLM-based extraction)

Database

PostgreSQL
